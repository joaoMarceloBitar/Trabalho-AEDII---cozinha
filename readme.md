# Desafio na cozinha    
### Trabalho AED II

### briefing:
Erick Jacquin precisa de ajuda. A falta de padrão nos cardápios, o acesso lento às
informações das receitas e a má organização dos ingredientes estão deixando o
chef irritado. Em uma cozinha profissional, encontrar rapidamente uma receita,
saber quais ingredientes estão disponíveis, organizar menus por custo, tempo de
preparo e dificuldade, além de recomendar pratos adequados para cada situação,
é essencial para o bom funcionamento do restaurante.
Além da desorganização no sistema de receitas, um novo problema surgiu:
receitas estão sendo adulteradas misteriosamente. Ingredientes somem, tempos
de preparo mudam e pratos clássicos aparecem com versões suspeitas.
| “Isso aqui virou sabotagem culinária!” — provavelmente diria Jacquin.
Ou seja, não basta apenas organizar o restaurante. É preciso garantir também a
integridade das receitas.
Diante desse problema, sua equipe, composta por até dois integrantes, foi
contratada para desenvolver o Desafio na Cozinha, um sistema inteligente de
gerenciamento de receitas e menus. O objetivo é organizar o acervo culinário do
restaurante, permitindo buscas eficientes, recomendações automáticas e
otimização na escolha dos pratos, além de garantir que as receitas não foram
alteradas indevidamente.
Nesse trabalho, você e sua dupla, se houver, deverão implementar um sistema
que utilize diferentes estruturas de dados, como Tries, Árvores B e Tabelas Hash,
além de aplicar pelo menos um algoritmo guloso para resolver um problema de
recomendação, busca ou otimização.
Para evitar sabotagens culinárias, o sistema deverá manter um identificador
baseado no conteúdo de cada receita, que permita verificar se uma receita foi
modificada e detectar inconsistências no sistema, como: receitas duplicadas
com conteúdo diferente, alterações não autorizadas, inconsistência entre os
dados armazenados e os resultados retornados pelas consultas.
O trabalho poderá ser desenvolvido em uma linguagem de programação de
preferência do aluno, desde que a escolha permita a implementação eficiente
das funcionalidades exigidas. O código entregue deverá estar claro, funcional,
organizado e devidamente documentado.
